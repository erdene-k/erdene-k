## 🚀 About Me

I'm a **Senior Backend Developer** in fintech, based in Ulaanbaatar, Mongolia 🇲🇳. I design payment gateways, loan platforms, and the quiet infrastructure that **500,000+ people** rely on without ever noticing it.

I started in frontend — shipping a mobile loan app to half a million users — then moved deeper into the stack: payment gateway integrations, document generation systems, and PDF data-extraction middleware for SME credit scoring. That full-stack path means I design APIs the way the people consuming them wish they were designed.

Currently at **Tavan Bogd NBFI**, where I lead code reviews, set system standards, and build the services that keep a non-bank financial institution running.

🌟 What I work on:

- 💳 **Payment gateway & banking service integrations**
- 📱 **Mobile loan applications** (PayOn v2 — 500K+ active users)
- 📄 **Document generation & PDF data-extraction pipelines**
- ⚙️ **RESTful APIs & microservices**
